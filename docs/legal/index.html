What is processed when you visit

This site is a set of static files with no application server and no database. When your browser requests a page, the hosting provider's web server records the request. GitHub states that “when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, regardless of whether the visitor has signed into GitHub or not”. Such log data typically comprises:

  • your IP address
  • the date and time of the request
  • the file or page requested
  • the browser and operating system reported by your browser
  • the referring page, where your browser sends one

The purpose is delivering the page and protecting the service against attack and abuse. The legal basis is Article 6(1)(f) GDPR; our legitimate interest is operating this page securely and reliably.

We should be precise about one thing: we cannot see this data. GitHub Pages provides no log access, no analytics and no visitor statistics to the owner of a site, so Veviad is unable to read, export or erase these entries. Retention is determined by GitHub. If you wish to exercise rights specifically over that log data, a request to GitHub will be more effective than one to us, and we will support you in making it.

Domain name resolution (Cloudflare)

The authoritative DNS for veviad.com is operated by Cloudflare, Inc. Cloudflare answers the DNS lookup that translates vterminal.veviad.com into an address, which is normally performed by your provider's or your chosen resolver rather than by your browser directly.

This hostname is configured in DNS-only mode, meaning Cloudflare is not a proxy or content delivery network in front of this page. It does not terminate the encrypted connection and does not receive the requests you make to this site; those go to GitHub. We mention this because a Cloudflare-proxied site would need to describe a considerably broader processing activity here.

No cookies, and why there is no consent banner

Section 25 of the German Telecommunications Digital Services Data Protection Act (TDDDG) requires consent before information is stored on, or read from, your terminal equipment unless it is strictly necessary. This page does neither: it sets no cookies and writes nothing to local storage, session storage or any other browser store. No consent is therefore required, and a banner asking for it would be meaningless.

The two small scripts on the home page run entirely in your browser and send nothing anywhere. One opens and closes the navigation menu; the other copies a command to your clipboard when you click the copy button.

The VTerminal application is not this website

VTerminal runs on your own Mac. Its default model performs inference locally, in the application's own process, and no terminal content, command or file is sent anywhere in that configuration. If you choose a cloud model and enter your own API key, your prompts go directly from your machine to that provider under their terms; Veviad does not operate an intermediary service and receives nothing. Model downloads are fetched from Hugging Face.

Knowledge can index documents with an on-device embedding model, in which case the document text and search queries remain on your Mac. If you deliberately choose OpenAI or Mistral embeddings, the extracted document chunks—and later search queries—are sent directly to that provider after an in-app disclosure. Anthropic is not used for embeddings. If you connect Qdrant, VTerminal sends extracted manifests, chunks, metadata and vectors to the Qdrant endpoint you configured; it does not upload the original document binaries. Veviad operates neither an embedding proxy nor a Qdrant service and receives none of this content.

Provider credentials, Hugging Face tokens, remote-model tokens and Qdrant keys are handled by the Rust backend and stored in macOS Keychain. The frontend receives only presence information, not the credential value. A keyed non-loopback connection uses HTTPS by default; allowing cleartext HTTP is an explicit advanced choice.

Update checks are off by default. If you click Check now or opt in to automatic checks, the app contacts GitHub's public Releases API and, when a newer release is available, its signed update manifest. Installing an update then downloads the signed archive from GitHub. These requests disclose ordinary connection data such as your IP address, time and the requested URL, plus a user-agent containing the installed VTerminal version. They do not contain terminal output, commands, files, prompts or saved sessions. The application contains no telemetry or usage analytics.
