## Terminal and agent reliability

- Queued agent messages retain their attachments and can be retried if delivery is unconfirmed, including after reopening a session.
- SSH agent commands require confirmation of an empty remote prompt and remain bound to their original target if the connection changes.
- Terminal input, output capture, resizing and search cleanup are more reliable.

## Runbooks

- Select the target platform when generating a runbook, and use the target shell's Docker context for approved interactive commands.
- A new macOS OrbStack cleanup example provides bounded cleanup steps.
