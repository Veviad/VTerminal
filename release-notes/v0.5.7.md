## Reliable Agent command completion

VTerminal now reconciles Agent commands with fresh completion evidence from the exact terminal command that ran.

- Remote and nested shells use a fresh nonce-bound probe and completion signal for every command, so a changed shell cannot inherit stale completion state.
- A terminal observation deadline now reports **completion unknown** instead of claiming that the command is still running or completed successfully.
- The Interrupt action is bound to the exact live command. A confirmed interrupt is preserved in the conversation and session archive.
- If an interrupt or result handoff cannot be confirmed, the Agent run stops before it can dispatch another command into an uncertain terminal.
- Reopened sessions reconcile legacy running cards as completion unknown rather than leaving a permanent running indicator.

## Cleaner streamed model output

Known model control envelopes no longer appear as literal XML-like tags in answers.

- The shared assistant renderer filters supported model-only control wrappers in both terminal conversations and Chat, including live streams and reopened conversations.
- User-authored text, inline code, fenced code blocks, and MCP result content remain literal.
- Agent tool instructions now reinforce the native structured finish call expected by each provider.
