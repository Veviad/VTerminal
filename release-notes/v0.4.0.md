## Faster on-device generation with MTP

VTerminal 0.4.0 adds automatic Multi-Token Prediction acceleration for all six built-in local chat models: Qwen3.5 4B and 9B, Qwen3.6 27B, and Gemma 4 E2B, E4B, and 31B.

- MTP runs automatically when compatible artifacts are installed. Every drafted token is verified by the target model before it is streamed.
- Existing model downloads keep working with standard decoding. Settings shows an optional **Upgrade to MTP** action.
- Qwen upgrades download a replacement GGUF. Gemma upgrades add a companion MTP file ranging from about 98 MB to 515 MB.
- If MTP cannot initialize or encounters a runtime problem, VTerminal continues with standard decoding instead of failing the chat.
- MTP needs some additional disk space and runtime memory. Performance gains vary by model, prompt, context, and hardware.

This release does not claim a fixed speed multiplier. VTerminal will publish performance figures only from a repeatable cross-platform benchmark matrix.
