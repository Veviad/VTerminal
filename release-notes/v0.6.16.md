## SSH connection health and command execution

- Check SSH shell health before every remote Agent command. If the connection does not answer, stop before sending the requested command and explain that the session may be stale or unverified.
- Offer a new SSH tab for an unresponsive saved-host session.
- Support strict unset-variable handling and common printf/eval aliases or functions in Bash, zsh, dash, and fish without breaking readiness or completion markers.
- Allow a slow SSH readiness response up to ten seconds within the command deadline, and release cancelled readiness checks promptly.
- Add saved-host keepalive defaults of 30 seconds and three unanswered checks, preserving explicit per-host options. New connections receive these defaults.
