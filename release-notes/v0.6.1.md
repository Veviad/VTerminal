## Windows starts without a separate OpenSSL installation

VTerminal 0.6.0 could fail before opening on Windows systems that did not already have OpenSSL 3 installed, reporting a missing `libssl-3-x64.dll` or `libcrypto-3-x64.dll`.

VTerminal 0.6.1 removes those accidental llama.cpp dependencies. Model downloads continue through VTerminal's existing rustls-based download path.

- Windows builds now audit the complete import closure of every load-critical executable and DLL.
- CI and installer verification fail when a required dependency is neither bundled nor provided by the supported platform runtime.
- Windows build caches were refreshed so the corrected llama.cpp libraries are rebuilt instead of restored from an affected cache.

## Improved AI documentation layout

The AI feature cards on the website now use the full page width, with three columns on desktop, two on narrower screens and one on mobile. This is a website-only layout correction and does not change application behavior.
