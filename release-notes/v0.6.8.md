## Remember Ask and Agent per tab

VTerminal now remembers whether each terminal tab was in Ask or Agent mode and restores that choice after restarting the app. Local and saved-host tabs can keep different modes, including tabs with saved AI conversations.

New tabs continue to use the configured default mode. Existing saved tabs from earlier versions use that default until their own choice is saved. Temporary Explain actions preserve the tab's last Ask or Agent selection.

Restoring Agent mode keeps command approval at Confirm and does not resume a previous run or pending command.
