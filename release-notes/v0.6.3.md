Version 0.6.3 includes the new default mode setting and the terminal creation and native web search fixes already merged in [#100](https://github.com/Veviad/VTerminal/pull/100).

## Choose the default terminal AI mode

**Settings → Agent → Default mode** now controls whether the terminal AI panel starts in Ask or Agent when you restart VTerminal, reopen terminal sessions, open a new terminal, or start a new terminal chat.

- **Always Ask** keeps the existing behavior and is the initial default.
- **Always Agent** starts terminal conversations in Agent mode.
- **Remember last used** saves your most recent explicit Ask/Agent selection and uses it across terminals and app restarts.

The separate Chat workspace keeps its Chat mode. Command approval starts at **Ask** for every new or restored conversation, including when Agent is the selected default.

## Create a terminal after closing the last tab

The terminal tab strip and its new-tab button remain available after you close the last terminal, so you can open another terminal immediately.

## Native web search in terminal conversations

Ask, Agent, and scheduled runs now offer native web search alongside native page fetching when internet access is enabled and the selected provider supports it.

Public web research uses the provider's native web tools. If those tools fail, the assistant reports the failure instead of switching to terminal commands. Explicit terminal-fetch requests and private-network access remain supported.
