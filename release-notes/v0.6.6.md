## Updated cloud model tiers

Fast, Balanced, and Max now use the current models for each provider:

| Provider | Fast | Balanced | Max |
| --- | --- | --- | --- |
| Anthropic | Claude Haiku 5.5 | Claude Sonnet 5.5 | Claude Opus 5.5 |
| OpenAI | GPT-6 Luna | GPT-6.1 Sol | GPT-6 Astra |
| Mistral | Mistral Small 4 | Mistral Medium 3.5 | Mistral Large 4 Preview |

Existing model selections follow their corresponding tier. Saved effort preferences carry forward, with unsupported choices adjusted to the nearest supported level. Mistral Large 4 remains a preview. On Sonnet 5.5, Off disables thinking before the answer while allowing progress updates between tool calls.

## OpenAI reasoning and tool calls

Built-in OpenAI models now use the Responses API. This fixes the HTTP 400 error caused by combining function tools and reasoning on Chat Completions. Reasoning state and tool-call links are retained across tool rounds and when reopening conversations, while older transcripts remain readable. Switching models keeps the conversation's ordinary text and tool history available.

Streamed text also handles Unicode characters split across network chunks correctly.

## SSH connection tracking

SSH tabs retain their remote connection state when the remote shell reports its own prompt. This fixes the misleading “not connected” status and Reconnect button while a remote session is active, prevents reconnecting inside that session, and keeps AI context associated with the remote host. Local shell tracking resumes when SSH exits.

## Dependency and Windows packaging updates

Updated JavaScript, Rust, Tauri, and build-workflow dependencies together, including compatibility changes for MCP clients, chat templates, and YAML parsing. Windows packaging recognizes the operating system's input-method library while continuing to reject missing third-party runtime DLLs.

Windows 11 support remains a preview for testing. The Windows installer is intentionally not Authenticode signed.
