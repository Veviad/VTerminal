## Ultrafast on-device AI for lighter laptops

VTerminal 0.5.6 adds Qwen3.5 2B as a seventh local chat model. It is an additional option, not a replacement. Qwen3.5 9B remains the default.

- The compact MTP-enabled GGUF is about 1.3 GB and is designed for laptops with 8 GB or more RAM.
- Its trained Multi-Token Prediction head accelerates generation automatically when supported by the active backend.
- If MTP cannot initialize or encounters a runtime problem, VTerminal continues with standard decoding.
- Qwen3.5 2B uses the same local Qwen tool-call format for Ask and Agent workflows across local, SSH, macOS, and Windows/WSL2 terminals.
- The 2B model prioritizes responsiveness and low memory use. Qwen3.5 4B and 9B remain available for more demanding multi-step work.

Performance gains vary by hardware, prompt, context, and generated content. Every drafted token is verified by the target model before it is streamed.
