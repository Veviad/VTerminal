## Agent permissions

- New Chat keeps your selected permission in the same interactive terminal. New tabs and reopened sessions start at Confirm.
- A command that arrives while you switch to Full can proceed once the permission change is acknowledged and the terminal is ready. SSH still asks you to confirm an empty prompt when it cannot verify one.
- The Agent toolbar wraps in narrow panes so the permission selector and collapse button stay visible.
