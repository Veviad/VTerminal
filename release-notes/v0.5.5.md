## Terminal tabs that scale

VTerminal now keeps every terminal usable when many sessions are open.

- Terminal tabs stay on one row inside a bounded, horizontally scrollable strip.
- The active terminal automatically scrolls into view after switching, restoring, or creating a session.
- A compact **All open terminals** menu provides fast access to every session while preserving running, failed, remote, and Sidecar indicators.
- Workspace controls, model actions, and the new-terminal button remain visible at narrow window sizes and with long terminal names.

## Restored chats return with their sessions

Archived Ask and Agent conversations now reopen with their visible messages and model context intact.

- Startup restoration reconnects saved chats to their terminal sessions.
- History clearly distinguishes reopening a terminal from reopening it with chat.
- Reopened chats return in safe Ask mode. Previous permission escalation and Agent mode are never rearmed automatically.

## Accurate terminal token usage

Token statistics now reflect the complete provider response for terminal Ask, Explain, Suggest, and MCP Ask interactions.

- Provider events are fully collected before final token totals are recorded.
- Terminal usage now follows the same accounting path as other model responses.
- **Statistics** is easier to find in the navigation, between SSH hosts and Updates.
