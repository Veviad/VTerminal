## Cleaner terminal output during agent runs

VTerminal's private shell checks and command-completion markers no longer appear as stray `printf` commands or shell-version variables in the terminal, including over SSH.

- Only the expected internal command echoes are hidden. Ordinary `printf` commands, their output, and the commands the agent runs remain visible.

## More reliable command results

Commands in zsh now stay associated with their results when shell history settings rewrite whitespace or prevent commands from being saved to history.

- If VTerminal cannot confirm a command's start or completion, the command card keeps available terminal output and reports the result as unknown. Unconfirmed commands are labeled **submitted as**.
- Output capture follows commands as scrollback moves and identifies truncated output when older lines are lost.
- Unknown-result messages distinguish observed terminal activity from confirmed command output and tell the agent to check the terminal before trying again.

Open a new terminal after updating to load the improved shell integration. Starting a new chat keeps the existing shell connection.

## Fresh terminal history for a new chat

**New chat** now clears previous terminal output, scrollback, and old chat command context while keeping the current prompt, shell, and SSH connection. Your shell history is preserved.

- **Settings → Terminal → Clear terminal on new chat** is enabled by default. Turn it off to keep terminal history when starting a new chat.
- Clearing waits while a full-screen program controls the display, then runs when the terminal can be cleared safely.
- When archiving is enabled, the outgoing conversation and terminal output remain available in Past sessions. Restoring the active session keeps its cleared history.

## Easier custom-instruction editing

The shared, Agent-only, and Chat/Ask fields in **Settings → Instructions** now highlight Markdown as you type.

- Formatting shortcuts add bold, italic, code, and links. Enter continues lists and quotes.
- Editors grow with the text and can be resized by dragging the corner.
- Changes save when you leave the field or press Command+Enter or Ctrl+Enter.

## Dependency and Windows build updates

Updated frontend and native dependencies, including the local inference engine. Windows packaging now selects the matching local-model runtime from the current build, avoiding stale DLLs left in the build cache.
