## Cleaner terminal output during agent runs

VTerminal's private shell checks and command-completion markers no longer appear as stray `printf` commands or shell-version variables in the terminal, including over SSH.

- Only the expected internal command echoes are hidden. Ordinary `printf` commands, their output, and the commands the agent runs remain visible.

## Fresh terminal history for a new chat

**New chat** now clears the terminal screen, scrollback, and old command context while keeping the current shell and SSH connection open.

- **Settings → Terminal → Clear terminal on new chat** is enabled by default. Turn it off to keep terminal history when starting a new chat.
- Clearing waits while a full-screen program controls the display, then runs when the terminal can be cleared safely.
- When archiving is enabled, the outgoing conversation and terminal output remain available in Past sessions. Restoring the active session keeps its cleared history.

## Easier custom-instruction editing

The shared, Agent-only, and Chat/Ask fields in **Settings → Instructions** now highlight Markdown as you type.

- Formatting shortcuts add bold, italic, code, and links. Enter continues lists and quotes.
- Editors grow with the text and can be resized by dragging the corner.
- Changes save when you leave the field or press Command+Enter or Ctrl+Enter.
