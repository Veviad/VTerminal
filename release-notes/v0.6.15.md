## SSH Agent execution

- Full and automatic Agent modes now show an empty-prompt confirmation when the SSH terminal has not yet been verified. This fixes commands repeatedly returning “not run” without offering the confirmation needed to proceed.
- After the first confirmed command succeeds, subsequent commands reuse the verified prompt. Typing into the terminal, reconnecting, or an expired verification requires fresh confirmation.
- Selecting Full while a remote command is pending keeps the prompt confirmation in place. Skip and Stop remain available before execution begins.
- Clarify that **Shell integration (command blocks)** initializes local shells and does not install integration on SSH hosts.

Command permissions, private-output protection, and existing conversation archives are preserved. No database migration is required.
