## Windows startup and local agents

Windows startup prepares WSL in the background and shares the result across terminal tabs. Background checks and command helpers no longer open extra console windows. If preparation times out, retry from the startup screen without restarting VTerminal.

This release fixes a native abort when starting generation with built-in Qwen MTP models, including Qwen3.5 2B. The local engine now loads the tensors required for speculative generation. CPU fallback explicitly excludes GPU execution, and cancelled local inference retains its resource guard until native work finishes.

Windows installer verification now exercises real Qwen3.5 2B generation with both MTP and standard decoding against the installed runtime DLLs.
