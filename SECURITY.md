# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Latest published release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not open a public issue or discussion for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/Veviad/VTerminal/security/advisories/new)
to send the affected component, reproduction steps or proof of concept, potential
impact, and any suggested mitigation. Remove secrets and personal data from the
report unless they are essential to reproducing the issue.

You should receive an acknowledgement within seven days. Status updates will be
provided through the private advisory while the report is validated and remediated.
Please allow time for a coordinated fix and release before publishing details.
